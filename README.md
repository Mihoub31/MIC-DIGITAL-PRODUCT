# MIC Digital Product

Site statique HTML/CSS/JavaScript. Le fichier `render.yaml` configure son
hébergement sur Render sans étape de compilation.

## Déployer sur Render

1. Dans Render, choisissez **New > Blueprint** et connectez le compte GitHub qui
   a accès à `Mihoub31/MIC-DIGITAL-PRODUCT`.
2. Sélectionnez ce dépôt et sa branche `main`.
3. Vérifiez le service `mic-digital-product` détecté depuis `render.yaml`, puis
   cliquez sur **Apply**.

Render publiera le contenu du dépôt et redéploiera le site aux prochains
changements de la branche connectée.
